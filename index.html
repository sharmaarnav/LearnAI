How AI Actually Works

Start with the simple version: AI learns patterns from examples, then uses those patterns to make predictions, generate answers, or take actions.

🤖 Artificial Intelligence
AI is software that performs tasks normally associated with human intelligence: understanding language, recognising images, making recommendations, planning, summarising, and generating new content.
Simple exampleA spam filter learns from thousands of emails and predicts whether a new email is spam or legitimate.
✨ Generative AI
Generative AI creates new text, code, images, audio, or video. It does not copy one exact item; it generates a new output based on learned patterns.
Simple exampleYou ask for a policy summary and the AI writes a new summary in plain English.
📊 Machine Learning
Machine learning is a subset of AI where systems learn from data instead of relying only on hand-written rules. The model finds patterns and uses them on new examples.
Simple exampleInstead of programming every fraud rule manually, you train a model on past transactions labelled fraud or legitimate.
Features, labels, and predictions
Inputs are features, the expected answer is a label, and the model output is a prediction. Training adjusts the model until predictions become more accurate.
🧠 Deep Learning
Deep learning uses neural networks with many layers. Early layers learn simple patterns, while deeper layers combine them into more complex ideas.
Simple exampleIn image recognition, early layers detect edges, later layers detect eyes or wheels, and final layers classify a face or car.
Why depth matters
Many layers allow models to represent language, images, code, and audio in rich internal forms. Modern LLMs are deep learning systems built with transformers.

Agentic AI — The Full Picture

Agentic AI can plan, use tools, observe results, and continue toward a goal. This section explains what that means in practical terms.

🎯 Goal-driven AI
A chatbot answers a message. An agent can pursue a goal by breaking it into steps and using tools.
Simple exampleInstead of explaining how to research competitors, an agent searches, reads, summarises, and drafts a report.
Reason → Act → Observe
The agent decides what to do, calls a tool, reads the result, and decides the next step. This loop continues until done or escalated.
✅ Can do
✓Research, summarise, draft, code, classify, retrieve data, and automate repeatable workflows.
✓Use tools such as search, files, calendars, APIs, and code execution when permissioned.
❌ Cannot safely do alone
✗Make high-impact legal, medical, security, financial, or employment decisions without human oversight.
✗Guarantee factual accuracy without trusted sources and verification.
🤖
Single-task agent
Narrow scope
Focused on one job, such as code review or email triage. Narrow scope improves reliability.
🌐
Multi-agent system
Collaboration
Specialist agents coordinate, such as researcher, writer, and reviewer.
Indirect prompt injection
AGENT · HIGH
Malicious content inside a page or email tells the agent to ignore instructions or misuse tools.
Over-permissioned tools
AGENT · MEDIUM
An agent with too many permissions can cause damage if compromised or confused.
Human-led automation
The safest near-term future is agents handling routine work with humans approving important actions.

AI Threat Landscape

AI systems combine instructions, data, models, tools, and infrastructure. Each layer creates new attack surfaces.

Training Data Poisoning
DATA · HIGH
Attackers inject malicious examples so the model learns bad patterns or hidden backdoors.
Private Data Leakage
DATA · MEDIUM
Sensitive data in training or prompts can appear in logs, outputs, or downstream systems.
Jailbreaking
MODEL · HIGH
Crafted prompts try to bypass safety behaviour and make the model produce restricted content.
Model Extraction
MODEL · MEDIUM
An attacker repeatedly queries an API to copy model behaviour or steal valuable capability.
Prompt Injection
INFERENCE · HIGH
User or retrieved content tries to override trusted instructions.
Unsafe Output Handling
INFERENCE · MEDIUM
AI output inserted into code, SQL, or HTML without validation becomes an injection risk.
Tool Abuse
AGENT · HIGH
A compromised agent calls tools outside intended scope.
Memory Poisoning
AGENT · MEDIUM
Malicious information stored in long-term memory influences future behaviour.
Malicious Model Files
SUPPLY CHAIN · HIGH
Unsafe model formats can execute code when loaded. Prefer safe serialisation.
Dependency Confusion
SUPPLY CHAIN · MEDIUM
Malicious packages impersonate trusted AI libraries or plugins.
Prompt Logs with Secrets
MLOPS · HIGH
Prompts and traces may contain credentials, PII, or confidential business data.
Cost-based DoS
MLOPS · LOW
Attackers can send expensive prompts that maximise token usage and cloud cost.

Commonly Asked Questions Around AI

Quick answers to the questions people ask most often when they start learning AI.

Why do LLMs hallucinate?
They predict likely text, not guaranteed truth.
+

LLMs generate words that fit the context. If the model lacks reliable evidence, it may still produce a confident-sounding answer.

Simple exampleAn AI may invent a fake case citation because it looks like the pattern of legal writing.
Can AI replace humans?
It can automate tasks, but humans remain essential for judgement and accountability.
+

AI can help with drafting, summarising, coding, searching, and analysis. Humans are still needed for goals, ethics, quality control, and high-impact decisions.

Is confidential data safe in AI tools?
Only if the tool, policy, and data handling are approved.
+

Use approved enterprise tools, understand logging and training settings, and avoid sending secrets to unmanaged services.

What is RAG?
Retrieval before generation.
+

RAG finds relevant documents first, gives them to the model, and asks the model to answer from that evidence.
